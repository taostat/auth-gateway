This demo relies on the auth gateway's OIDC discovery endpoint at {authority}/.well-known/openid-configuration. The oidc-client-ts library automatically fetches this document to discover the authorization, token, and JWKS endpoints. Make sure the gateway is running and the client_id is registered before attempting to log in.
